# Tray Connect — preparación

El Tray oficial será proveedor de Boss Tray Manager vía `tray-provider`
certificado en CUSTOM V2, con independencia del runtime Open y estado compartido.
No instalar `systemd-user` session-controller histórico ni autostart de host.
La semántica del cierre X/ocultar debe aprobarse antes de escribir código.
El archivo `assets/neebles-connect-tray-icon.png` existe bajo el repo.
